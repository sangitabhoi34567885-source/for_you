# 🌐 Modern Website

A simple, modern, and responsive website built using **HTML, CSS, and JavaScript**.  
This project demonstrates a clean website layout with navigation, service cards, animations, responsive design, and a dark mode feature.

## ✨ Features

- 📱 **Responsive Design** – Works on desktop, tablet, and mobile devices.
- 🧭 **Navigation Bar** – Easy navigation between Home, Services, and Contact sections.
- 🎨 **Modern UI** – Clean layout with attractive colors and card designs.
- 🌙 **Dark Mode** – Toggle between light and dark themes.
- ✨ **Animations** – Smooth fade-in and hover animations.
- 💻 **Service Cards** – Displays Web Design, UI Design, and JavaScript services.
- 📩 **Contact Button** – Allows users to contact through email.

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling, responsive design, animations, and dark mode
- **JavaScript** – Dark mode functionality

## 📂 Project Structure

```text
Modern-Website/
│
└── index.html
```

All HTML, CSS, and JavaScript code is included in the `index.html` file.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Explore the website.

## 🌙 Dark Mode

Click the **🌙 Dark Mode** button to switch the website to dark mode.

Click it again to return to the normal light mode.

## 📱 Responsive Design

The website automatically adjusts its layout for smaller screens.

On mobile devices:

- Navigation items are arranged vertically.
- The hero heading becomes smaller.
- Service cards are displayed in a single column.

## 📸 Sections

### Home
Introduces the website and provides an **Explore** button and **Dark Mode** button.

### Services
Displays three services:

- 💻 Web Design
- 🎨 UI Design
- ⚡ JavaScript

### Contact
Provides a simple contact section with an email button.
